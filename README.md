## 📁 Структура исходного кода

- `Source/Server/` — Основной проект выделенного сервера:
  - `Program.cs` — Точка входа, инициализация хранилища `Repository`, запуск сетевого сокета на порту 19019.
  - `SessionServer.cs` — Обработка сессий игроков, авторизация, валидация пакетов `ModelPlayToServer`.
  - `ServerManager.cs` — Управление циклом сохранения мира, очередями пакетов и синхронизацией.
  - `ChatService/` — Обработка чатов, каналов государств и интеграция с Discord-ботом.
- `Source/Client/UnionDll/` — Сетевые протоколы и модели передачи данных `OCUnion`.
- `Source/Server.sln` — Автономное решение для сборки сервера через Visual Studio 2022 / `dotnet build`.

---

## 🛠 Сборка из исходников

```bash
cd Source
dotnet build Server.sln -c Release -p:RimWorldFolder="C:\Путь\К\RimWorld\\"
```
Скомпилированный сервер автоматически сохраняется в `BuildOutput/Server/Release/Server.exe`.
